How to print

  1. Use the Mac at the 2nd register.
  2. Make sure the Zebra is on, plugged into that Mac, and loaded with 2″ × 1″ labels.
  3. Fill in the address below, check the preview, then click Copy print command.
  4. Open Terminal (⌘ Space, type Terminal, Return), paste with ⌘V and press Return.
If something goes wrong
  • Skips labels or prints across the gaps: hold Pause and Cancel on the Zebra together for 2 seconds to recalibrate, then print again. Do this whenever the label size changes.
  • "Unknown destination": run lpstat -p in Terminal and tell Jon what printer name it shows.
  • Stop a print that's running: paste printf '~JA' | lpr -P Zebra_Technologies_ZTC_ZD410_203dpi_ZPL -o raw
  • Terminal shows a > and nothing happens: quit Terminal, reopen it and paste again.

To look up customers, paste the MRM Photos Airtable key (starts with pat). Devices with the Hub set up are connected automatically.
